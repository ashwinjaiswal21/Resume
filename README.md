# Ashwin Jaiswal — Resume Website

A responsive, single-page resume website.

## Files
- `index.html` — resume content
- `style.css` — page styling

## Publish with GitHub Pages
1. Upload both files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save and wait for deployment.
